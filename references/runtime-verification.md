# 光学宏实机与数值验收

## 最小执行验证

在目标版本上，先在可丢弃的会话或镜头副本中验证关键命令块。保留原始回显，记录失败发生前的阶段标记。涉及分析模式时，分别验证进入选项、设置参数、执行和取数。运行结束后检查本宏占用的镜头、配置、输出、Buffer 或文件资源是否符合约定。

- **CODE V**：用 `IN "codev-smoke.seq"` 执行包内 [codev-smoke.seq](../assets/probes/codev-smoke.seq)，文件名换成目标电脑上的实际路径。省略参数时预期 `CODEV_SMOKE_OK` 和数值 `14`，显式传入 `4` 时预期 `30`，传入 `2.5` 时预期 `CODEV_SMOKE_INVALID_INPUT`。这组预期值来自整数平方和。用例覆盖参数传递、变量、条件和循环。记录 `(CVV)` 的完整字符串，必要时再为 Buffer、分析或编辑器命令建立任务专用探针。
- **ZPL**：在目标 OpticStudio 的 Edit/Run 执行当前宏，记录预期输出或结果文件。为使用分析命令的任务，至少确认实际生成了请求的分析类型，并记录生效的设置。
- **ZOS-API**：在目标 OpticStudio 版本中验证实际连接、许可证和本任务的关键接口。记录结果集合类型、维度和单位，随后验证对象关闭或会话恢复。

包内用例的执行结果应由目标软件产生。对任何未实际运行的版本，只记录静态检查与资料证据。

## 数值验收

先定义基准、匹配键、单位和误差，再运行比较。用同一镜头副本及同一配置、视场、波长、焦面、算法、采样和补偿条件。优先使用软件原生分析或独立可手算值，保留原始数据便于重放。按表面、组件、配置等真实标识匹配，检查总数、缺行、重复和顺序，随后对比数值。对解析自文本的结果，把显示舍入纳入误差，缺失值应与真实的 0 区分。

| 工作类型 | CODE V 优先对照 | 必查边界 |
| --- | --- | --- |
| 镜头数据与处方导出 | 逐面核对 LDM 显示的半径、厚度、材料和结构号 | 平面、物像面、镜片编号与面编号、多重结构 |
| 光线、MTF 或像质分析 | 原生分析在同一条件下的原始输出 | 视场和波长匹配、方向和坐标约定、追迹失败、单位与精度 |
| 修改模型、公差或优化 | 在副本上单独施加已知变化，再运行同定义分析并比较状态 | 零输入、正负号、选中和未选中的对象、异常后的恢复 |
| 多结构或批处理 | 先核对单个镜头的每个目标结构，再扩至多个镜头 | 空列表、单结构、个别失败、重跑时结果归属和文件覆盖 |

例如报告有四位小数时，先确认基准保留的有效位数，再按指标设定绝对误差。若需要相对误差，明确参考值接近 0 时的规则。比较公差变化量和直接扰动结果时还要核对二者的计算方法、补偿和近似条件。

## 结果记录

每条实机用例记录软件名称与完整版本、宏版本、运行方式、镜头标识和参数、基准来源、预期与实际结果、误差、日志和验证等级。故障用例同时记录预期失败点和实际会话状态。只保留经过验证的通用写法，镜头、路径与结果样本按实际授权存放。不同版本的同一用例可以有不同结论。
